## Selected Projects

### 01. S.H.I.E.L.D — AI-Powered Phishing Detection

The project explores how pretrained language models can be fine-tuned for security-oriented classification tasks and evaluated against potentially malicious email content.

**Focus areas:** NLP · Transformer Models · Text Classification · Cybersecurity

### 02. CommuteFlow — Corporate Transportation Platform

A backend-focused corporate employee transportation platform designed to manage transportation workflows.

Built with Java and Spring Boot, the project explores structured backend development, relational data management, and application security.

**Focus areas:** REST APIs · Authentication · Backend Architecture · Relational Databases

**Stack:** Java · Spring Boot · Spring Security · PostgreSQL

[Source Code](https://github.com/shashankpandey04/CommuteFlow)

---

### 03. CyniGPT — Building a Language Model from Scratch

An exploration of decoder-only Transformer architecture implemented from scratch using PyTorch.

The project includes a custom SentencePiece tokenizer, multi-head self-attention, causal masking, and autoregressive text generation.

Rather than treating language models as black boxes, this project focuses on understanding the architecture and mechanics behind next-token prediction.

**Focus areas:** Transformers · Self-Attention · Tokenization · Deep Learning

**Stack:** Python · PyTorch · SentencePiece

[Source Code](https://github.com/shashankpandey04/CyniGPT)

---

The platform serves **300+ communities and 40,000+ users**, with functionality spanning moderation, activity tracking, automated workflows, and community management.

**Focus areas:** Event-Driven Systems · Automation · Real-Time Applications · Backend Architecture

**Stack:** Python · FastAPI · MongoDB · discord.py

[Source Code](https://github.com/shashankpandey04/Cyni)

### 05. AWS LPU Operations Platform
